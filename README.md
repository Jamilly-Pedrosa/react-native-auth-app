> App de Autenticação — React Native + Expo

---

# ★ Sobre

Este projeto foi desenvolvido como uma prática de introdução ao React Native utilizando Expo.

A proposta foi explorar, na prática, como funciona o desenvolvimento de aplicações mobile com React Native, 
criando uma interface simples de autenticação, composta pelas telas de login e cadastro.

Além de praticar a construção de interfaces para dispositivos móveis, o projeto serviu como meu primeiro 
contato com o Expo, permitindo conhecer sua estrutura, ferramentas e fluxo de desenvolvimento.

---

## ✎ Objetivos

- Conhecer o funcionamento do React Native;
- Ter o primeiro contato com o Expo;
- Praticar a criação de interfaces mobile;
- Trabalhar com componentes e propriedades do React Native;
- Explorar campos de entrada e formulários;
- Compreender melhor a estrutura de um projeto mobile.

---

## ✎ Funcionalidades

- 🔐 Tela de login;
- 📝 Tela de cadastro;
- 📧 Campo para e-mail;
- 🔑 Campo para senha;
- 👤 Campo para nome;
- 🔄 Confirmação de senha;

---

## 📱 Telas

### **Login**

Tela destinada à entrada do usuário na aplicação, contendo campos para e-mail e senha.

### **Cadastro**

Tela para criação de uma nova conta, com campos para nome, e-mail, senha e confirmação de senha.

---

## ★ Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- Expo Go

## ➜ Como executar o projeto

👉 É necessário ter o Node.js e o Expo configurados no ambiente de desenvolvimento.

1. Clone o repositório:

```bash
git clone https://github.com/Jamilly-Pedrosa/react-native-auth-app.git
```

2. Acesse a pasta do projeto
   
4. Instale as dependências: ```npm install```

5. Inicie o projeto: ```npx expo start```

₊⊹ Depois, é possível executar a aplicação utilizando um dispositivo físico com o Expo Go ou um emulador compatível.
